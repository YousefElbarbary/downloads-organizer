# Downloads Organizer

A Python-based file organization tool that automatically sorts files in a directory into categorized folders based on their file extensions.

> **Current version: v0.1.0 — Proof of Concept**

## Overview

Downloads Organizer scans a directory, identifies files based on their extensions, and moves them into the appropriate category and subcategory folders.

The categorization rules are defined externally in a YAML configuration file, allowing file types and folder structures to be changed without modifying the Python code.

The project was built as a modular Python application with separate responsibilities for configuration, scanning, classification, and file organization.

---

## Features

### v0.1.0

- Scan a directory for files.
- Ignore directories.
- Categorize files based on their file extensions.
- Use a YAML configuration file to define categories, subcategories, and extensions.
- Create destination directories automatically when they do not exist.
- Move files into their appropriate destination.
- Handle unknown extensions by placing them in an `Others` folder.
- Handle extension capitalization (`.PDF`, `.pdf`, `.Pdf`, etc.).
- Handle duplicate filenames by automatically renaming the incoming file:
  - `file.pdf`
  - `file (1).pdf`
  - `file (2).pdf`
  - etc.
- Use `pathlib` for filesystem operations.
- Use a modular `src` package structure.

### Currently Not Included

The following functionality is intentionally outside the scope of v0.1.0:

- Periodic/automatic scanning.
- User-configurable target directories.
- Recursive directory scanning.
- A command-line interface.
- A graphical user interface.
- Advanced error handling and recovery.
- Automated test coverage.

## How It Works

The application is divided into several modules, each with a specific responsibility:

    categories.yaml
           |
           v
       config.py
           |
           v
     Extension Map
           |
           v
       scanner.py
           |
           v
      List of Files
           |
           v
     classifier.py
           |
           v
     Destination Path
           |
           v
      organizer.py
           |
           v
        File Moved

The high-level `main.py` module coordinates these components.

### `config.py`

Loads the YAML categorization configuration and converts it into a dictionary where file extensions map to their destination paths.

This allows the classifier to perform fast dictionary lookups instead of repeatedly searching through the YAML structure.

### `scanner.py`

Scans the target directory and returns the files located directly inside it.

Directories are ignored in v0.1.0.

### `classifier.py`

Receives a file and the extension map generated by `config.py`.

It extracts the file extension, normalizes its capitalization, and returns the appropriate destination path.

Unknown extensions are mapped to the `Others` destination.

### `organizer.py`

Responsible only for filesystem operations.

It:

1. Creates the destination directory if necessary.
2. Checks whether a file with the same name already exists.
3. Generates a new filename if necessary.
4. Moves the file to its destination.

### `main.py`

Acts as the high-level application layer and coordinates the other modules.

The v0.1 workflow is:

    Load configuration
           |
           v
    Scan directory
           |
           v
    For each file:
           |
           +--> Classify file
           |
           +--> Build destination path
           |
           +--> Organize file
           |
           v
        Finished

## Configuration

File categorization is defined through YAML rather than being hardcoded into the Python code.

This makes it possible to add or modify categories and extensions without changing the classifier.

Example:

    Documents:
      PDF:
        - .pdf
      Word:
        - .doc
        - .docx

    Media:
      Images:
        - .jpg
        - .jpeg
        - .png
      Videos:
        - .mp4
        - .mkv

The configuration is processed by `config.py` and converted into an extension-to-path mapping used by the classifier.

Unknown extensions are assigned to `Others`.

## Installation

Clone the repository:

    git clone https://github.com/YousefElbarbary/downloads-organizer.git
    cd downloads-organizer

Create a virtual environment:

    python -m venv .venv

Activate the virtual environment.

On Windows PowerShell:

    .venv\Scripts\Activate.ps1

Install the project:

    python -m pip install -e .

---

## Usage

The target directory is currently defined directly in `main.py`.

For example:

    downloads_folder = Path("D:/Downloads")

Run the application from the project root:

    python -m downloads_organizer.main

The program will scan the configured directory and organize the files according to `categories.yaml`.
